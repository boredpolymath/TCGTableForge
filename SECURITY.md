# Security policy

## Supported versions

Security fixes are made against the latest version on the `main` branch and the version currently deployed on GitHub Pages.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through the **Report a vulnerability** option on the repository's GitHub **Security** tab. Do not open a public issue for an unpatched vulnerability.

Include steps to reproduce the issue, its likely impact, and any relevant browser or device details. Please allow maintainers reasonable time to investigate and prepare a fix before sharing the issue publicly.

TableForge stores project data in browser storage and does not provide a server or account system. Reports about data exposure, unsafe imports or exports, cross-site scripting, or compromised dependencies are especially helpful.
